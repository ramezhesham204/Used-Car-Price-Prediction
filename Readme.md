    "# Used Car Price Prediction — Project Overview\n",

    "## 🚗 Dataset Overview\n",

    "- **Source:** `Used_Car_Prices.csv`\n",

    "- **Features:**\n",
    "  - `brand` (Categorical): Car manufacturer (Maruti, Hyundai, Honda, Skoda, BMW, etc.)\n",
    "  - `km_driven` (Numerical): Total distance driven in kilometers\n",
    "  - `fuel` (Categorical): Fuel type (Diesel, Petrol, LPG, CNG, Electric)\n",
    "  - `owner` (Categorical): Ownership history (First Owner, Second Owner, Third Owner, etc.)\n",
